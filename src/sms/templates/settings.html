Settings

Who you are signed in as

{% if viewer.via == "open" %}

Nobody, and that is deliberate. This server is running with SMS_AUTH_DISABLED set, so it asks nobody to sign in and treats every visitor as an administrator. There is no “dev” account and no password anywhere — the name is a placeholder for “whoever is looking”.

It is a development setting. The app refuses to start with it set unless SMS_DEBUG is also set, so it cannot be left on by accident in the deployed stack.

To turn authentication on, remove SMS_AUTH_DISABLED and set SMS_OIDC_ISSUER, SMS_OIDC_CLIENT_ID and SMS_OIDC_CLIENT_SECRET to an authentik application. Those live in .sheetmusicshelf.env beside the compose file; the compose file passes them in and holds no secrets itself.

{% elif viewer.via == "password" %}

Signed in with the library's shared password.

One password for the whole library, set as SMS_PASSWORD in .sheetmusicshelf.env beside the compose file. There are no accounts: anyone with the password has the run of the catalogue, which is the right shape for one household and the wrong one for more than that. Changing it means editing that file and restarting the stack, which signs every device out.

For real accounts, set SMS_OIDC_ISSUER, SMS_OIDC_CLIENT_ID and SMS_OIDC_CLIENT_SECRET to an authentik application. That takes precedence over the password.

Ingest drop folder

Drop PDF files into the /library/ingest folder inside the container (or its mapped host path), then click the button below. The worker will scan the files, catalogue them, file them into the library, and empty the folder.
